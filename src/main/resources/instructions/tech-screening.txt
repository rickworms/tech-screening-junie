INTRODUCTION
FUNCTIONAL REQUIREMENTS
Backend
The backend should be able to read and store JSON files containing bands and songs. CRUD (Create/Read/Update/Delete) operations should be performed on the stored data. CRUD functionality includes: 
•	(C): Adding new band(s) or songs with all the details found in the JSON, ensuring that band names are not duplicated.
•	(R): Searching for a band by name or songs by genre (for when you're in the mood for Finnish Death Metal).
•	(U): Updating all information related to bands and songs based on their respective IDs.
•	(D): Deleting a band or song based on its ID.

We are only interested in the following when reading the data:
•	All bands with the genre "Metal."
•	All songs released before 2016. 

The JSON files can be served through the Web API itself as static files. You can find the required files here: 
•	https://www.teamrockstars.nl/sites/default/files/artists.json
•	https://www.teamrockstars.nl/sites/default/files/songs.json

Frontend 
No frontend implementation is expected for this assignment, and it should be possible to test the web API using tools like Postman or cURL.
TECHNICAL REQUIREMENTS
Quality Assurance
We anticipate that this web app will become very popular. With a widely-used app, good unit tests and readable code are essential. This application will be maintained by other developers for a long time, so we expect unit tests for the backend, clear naming, and documentation as needed.
